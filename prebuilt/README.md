# Prebuilt binaries

Place the following files here before building:
- `Image.gz` — prebuilt kernel image
- `dtb` — device tree blob
- `recoverydtbo` — recovery dtbo image

These can be extracted from the official TWRP image or built from kernel source.
Reference: https://github.com/Ragekill3377/TWRP-SM-A025F-OS12
