Install

  1. Check the model under Settings > About phone. This tree targets SM-A025F and SM-A025F/DS only.
  2. Unlock the bootloader. Back up BL, AP, CP, CSC and vbmeta from stock firmware before touching recovery.
  3. Download recovery.tar from the latest release. In Odin, turn Auto Reboot off, load the file into AP, and flash. After PASS, boot straight to Recovery before Android starts.
  4. For Heimdall, write recovery.img to the recovery partition with heimdall flash --RECOVERY recovery.img --no-reboot. Do not write it to boot.

The release file named recovery.tar.md5 is the output of md5sum recovery.tar. It is a checksum, not an Odin package. Check it with md5sum -c recovery.tar.md5.

Known gaps

  • #8: the phone is not detected in Samsung Download Mode. USB enumeration dies outside recovery, so this needs a cable, PC port and host test on the device.
  • #7: wipe and mount returned "Block device required" on dynamic partitions. The fstab fix is in the tree; wider wipe testing is still open.
  • #9: autoreboot cancel does not persist and leaves watcher processes alive.
  • #4: touch firmware is missing for some panel variants.

Build from source

Use minimal-manifest-twrp/platform_manifest_twrp_aosp, branch twrp-12.1, target recoveryimage, device tree at device/samsung/a02q. The Actions workflow runs that build on pushes to main.

Flaşlama

  1. Ayarlar > Telefon hakkında ekranından modeli kontrol edin. Bu ağaç yalnızca SM-A025F ve SM-A025F/DS içindir.
  2. Bootloader kilidini açın. Recovery'ye dokunmadan önce stock firmware'den BL, AP, CP, CSC ve vbmeta yedeği alın.
  3. Son sürümden recovery.tar dosyasını indirin. Odin'de Auto Reboot'u kapatın, dosyayı AP alanına yükleyin ve flaşlayın. PASS sonrası Android açılmadan doğrudan Recovery'ye girin.
  4. Heimdall ile recovery.img dosyasını recovery partition'ına yazın: heimdall flash --RECOVERY recovery.img --no-reboot. Boot partition'ına yazmayın.

Sürümdeki recovery.tar.md5 dosyası md5sum recovery.tar çıktısıdır. Odin paketi değildir. md5sum -c recovery.tar.md5 ile doğrulayın.
