TWRP for Samsung Galaxy A02s

Unofficial TWRP 12.1 custom recovery for SM-A025F and SM-A025F/DS, codename a02q, Qualcomm Snapdragon 450 (MSM8953).

Flash at your own risk. Back up stock firmware (BL, AP, CP, CSC), back up vbmeta, and unlock the bootloader before using any recovery image.

What is here

The repository contains the complete device/samsung/a02q TWRP 12.1 device tree: recovery ramdisk, fstab, prebuilt kernel and DTB, touch firmware handling, USB and autoreboot scripts, and GitHub Actions workflows that build recovery.img and recovery.tar for Odin.
